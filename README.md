# Aibdogs Trainer-Cockpit

Desktop-App für Trainer des EHC Bad Aibling: Aufstellung, Spielplan, Kader, Statistik, Gegneranalyse und Trainingsvorbereitung.

## Download

Den aktuellen Installer findest du unter "Releases" rechts auf dieser Seite. Nach der ersten Installation aktualisiert sich die App automatisch.

Die App speichert alle Daten nur lokal auf dem eigenen Rechner – dieses Repository enthält ausschließlich die Installer.
